# 誓死效忠ICBC（Faithful-to-ICBC）

> 基于 Python + Pygame 的横版跑酷跳跃小游戏，玩法类似 Chrome 离线恐龙游戏：躲避障碍、收集金币、冲击排行榜。

## 游戏特色

- **三档难度**：简单 / 中等 / 困难，初始速度、障碍密度、危险物比例各不相同。
- **圆形碰撞体**：比矩形判定更宽容，手感更好，游戏中按 `F1` 可实时查看碰撞圆。
- **生命值系统**：初始 3 条命，撞到其它银行扣 1 条，生命耗尽才结束游戏，受伤后有无敌帧闪烁保护。
- **本地排行榜**：分数与玩家姓名持久化保存在 `ranking.csv`，退出游戏后依然保留，开始界面直接展示前十名。
- **完整流程**：开始界面 → 游戏进行 → 结束结算（输入姓名保存成绩）→ 再玩一次 / 返回主菜单。

## 快速开始

```bash

conda create -n ICBC_love python==3.11
conda activate ICBC_love
conda install pygame==2.6.1

# 2. 进入项目目录
cd /path/to/Faithful-to-ICBC-260831

# 3. 启动游戏
python main.py
```

| 按键 | 功能 |
| --- | --- |
| `空格` | 跳跃 |

| 鼠标左键 | 点击难度按钮、保存分数、再玩一次、主菜单 |


## 难度设置

| 难度 | 初始速度 | 生成间隔 | ABC | CCB | ICBC |
| --- | --- | --- | --- | --- | --- |
| 简单 | 5 | 1500 ~ 2600 ms | 55% | 15% | 30% |
| 中等 | 8 | 1100 ~ 2000 ms | 40% | 35% | 25% |
| 困难 | 12 | 700 ~ 1400 ms | 30% | 50% | 20% |

- CCB与ICBC会在世界速度基础上额外加速，并可能出现在地面或空中。
- ABC障碍始终贴地，与世界同速移动。

## 计分规则

```
总分 = 背景移动距离（像素） + ICBC数 × 100
```

分数实时显示在屏幕左上角，同时显示已收集ICBC数。

## 排行榜说明

`ranking.csv` 采用 UTF-8 编码，格式如下，游戏启动时自动读取，保存成绩时自动追加：

```csv
name,score
Alice,15800
Bob,12450
```

- 文件不存在或为空时自动处理，开始界面显示「暂无记录」。
- 开始界面按分数从高到低展示前 10 条记录。


## 常见问题

**Q：画面出现残影 / 拖影？**
A：早期版本背景使用正数偏移绘制，导致屏幕大片区域未被重绘。现已改为「先清屏 + 负偏移循环平铺」，并对世界表面做整块贴图，彻底解决残影问题。

**Q：中文显示为方块？**
A：程序使用系统字体 `simhei`，Windows 默认可用；若在其他系统运行，可将 `pygame.font.SysFont("simhei", ...)` 替换为系统中文字体名。

**Q：想更换素材图？**
A：直接替换 `background.png` / `player.png` / `ABC.png` / `CCB.png` / `ICBC.png` 即可，程序按文件名加载；若文件名变化，同步修改 `main.py` 顶部的 `ASSETS` 字典。
